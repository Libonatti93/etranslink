# Sistema de marca Etranslink

Este diretório é a fonte de verdade para a identidade visual e verbal da Etranslink.

## Fundamentos

- **Propósito:** transformar informação logística em decisões e conexões.
- **Posicionamento:** mídia, inteligência e negócios para quem movimenta a América do Sul.
- **Personalidade:** direta, técnica, confiável, ágil e continental.
- **Assinatura PT:** Informação que movimenta. Conexões que entregam.
- **Assinatura ES:** Información que mueve. Conexiones que entregan.
